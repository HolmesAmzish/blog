# Gallery Public Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add public `/gallery` masonry (adaptive height, `showInGallery=true` only) with click-to-original lightbox, download and share.

**Architecture:** Reuse `GET /api/pictures` ( `PictureController.findGalleryPictures` ), add 4 public components (`GalleryPage/Masonry/Card/Lightbox`) using pure CSS `columns-*` + TanStack Query; no new backend.

**Tech Stack:** React 19, Vite 7, Tailwind 4, TanStack Query, React Router, Axios, lucide-react

**Spec:** `docs/superpowers/specs/2026-08-29-gallery-design.md`

## Global Constraints
- Gallery only `showInGallery=true`
- Keep original aspect ratio, no square crop
- List: `thumbnailUrl`, lightbox: `url`
- No new backend endpoint
- Style: black bg, white type, blue dot, 0.5px hairline, Tailwind only

- [ ] **Step 1: Create type** `public/src/types/picture.ts`

```ts
export interface PictureVo {
  id:number; filename:string; originalFilename:string; mimeType:string; size:number;
  url:string; thumbnailUrl:string|null; alt:string|null; showInGallery:boolean; tags:TagVo[]; createdAt:string;

```

- [ ] **Step 2: Create api** `public/src/api/gallery.ts`
```ts
import { get } from './client';
import type { PictureVo } from '@/types/picture';
import type { PageResponse } from '@/types/common';
export const fetchGallery = async (page=0,size=24):Promise<PageResponse<PictureVo>> =>
  get<PageResponse<PictureVo>>(`/api/pictures?page=${page}&size=${size}&sort=createdAt,desc`);
export const fetchPicture = async (id:number):Promise<PictureVo> =>
  get<PictureVo>(`/api/pictures/${id}`);
```

- [ ] **Step 3: Create hook** `public/src/hooks/useGallery.ts`
```ts
import { useQuery } from '@tanstack/react-query';
import { fetchGallery } from '../api/gallery';
export const useGallery = (page=0,size=24) => useQuery({
  queryKey:['gallery',page,size],
  queryFn:()=>fetchGallery(page,size),
  staleTime:5*60*1000, retry:1
});
```

```tsx
export function GalleryLightbox({picture,onClose,onPrev,onNext}:{picture:PictureVo|null;onClose:()=>void;onPrev:()=>void;onNext:()=>void}){
  if(!picture) return null;
  return <div className="fixed inset-0 bg-black/90 backdrop-blur-xl z-50 flex items-center justify-center p-4" onClick={onClose}>
    <img src={picture.url} alt={picture.alt||''} className="max-w-[92vw] max-h-[86vh] object-contain rounded-xl" onClick={e=>e.stopPropagation()}/>
    <div className="absolute bottom-4 left-1/2 -translate-x-1/2 flex gap-2">
      <a href={picture.url} download={picture.originalFilename} className="px-3 py-1.5 rounded-full bg-white text-black text-xs">Download</a>
      <button onClick={()=>navigator.clipboard.writeText(location.href)} className="px-3 py-1.5 rounded-full border border-white/20 text-xs">Copy link</button>
    </div>
  </div>;
}
```
